# NOTA DE COMPATIBILIDAD
# Con pandas 3.x el tipo de texto respaldado por PyArrow provoca una falla de
# segmentación al construir DataFrames dentro del hilo de trabajo que Streamlit
# crea en cada re-ejecución, es decir, cada vez que se mueve un filtro.
# `src/config.py` desactiva ese backend con `pd.options.future.infer_string`
# antes de crear cualquier DataFrame, de modo que el dashboard funciona tanto
# con pandas 2.x como con 3.x. Por la misma razón las tablas del dashboard se
# renderizan como HTML en lugar de `st.dataframe`, que convierte a Apache Arrow.
#
# La exportación de los PDF usa Google Chrome en modo headless. Si no está
# instalado, `src/documentos.py` deja igualmente los archivos HTML en docs/,
# que pueden imprimirse a PDF desde cualquier navegador.
